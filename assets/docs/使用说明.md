# Codex CLI + DeepSeek

1. 双击 `启动-Codex CLI.cmd`，在 `G:\Codex\projects` 启动 Pro 模型，适合日常 coding 与文件生成。
2. 仅首次配置或更换密钥时，双击 `配置-DeepSeek API Key.cmd`，输入 DeepSeek API Key。脚本会先请求 DeepSeek 模型列表验证密钥。
3. 其他一键操作都在 `quick-tools` 文件夹：`Start-Codex-Flash.cmd`（图片理解）、`Analyze-PDF-Flash.cmd`（前 30 页视觉分析）、`Analyze-PDF-Full.cmd`（任意长度 PDF 全量分析）、`Archive-Text.cmd`（网页/PDF/图片转 Markdown）、`Start-Codex-Here.cmd`（在当前项目目录启动）。

本机能力：代码编辑和终端命令、DOCX/XLSX/PPTX/PDF 生成、图片处理、图片/截图/扫描 PDF OCR、公开网页检索、公开网页读取和截图。具体命令见 `projects\AGENTS.md`。

Codex CLI、配置、会话记录、模型目录、Python 工具和加密密钥均在 `G:\Codex`。密钥使用 Windows DPAPI 加密保存于 `secrets\deepseek.dpapi`，不会写入配置文件或用户环境变量。

该方案是本地运行 Codex CLI、远程调用 DeepSeek API；并非下载模型权重后离线推理。DeepSeek 不支持图像生成、内置联网搜索、内置电脑操控或完整 MCP 工具调用。
